Featured Projects

Aviation Intelligence

AeroIntel — Aviation Intelligence RAG Platform

A production-grade, AI-powered aviation knowledge platform utilizing advanced Retrieval-Augmented Generation (RAG) to provide fast, contextual answers about commercial aircraft models, technical specifications, and international airlines.

Key Technical Highlights:

  • Document Ingestion & Chunking: Automated document processing pipeline ingesting 17 structured aviation domain documents partitioned into 48 semantically coherent document chunks.
  • Dense Embeddings: High-dimensional representation utilizing 384-dimensional dense sentence embeddings to capture deep domain semantics.
  • Pinecone Vector Database: Scalable vector search index on Pinecone with low-latency cosine similarity retrieval and namespace isolation.
  • Hybrid Retrieval & BM25: Dual-channel retrieval architecture integrating dense semantic vector search with sparse keyword search (BM25) for high precision and recall.
  • Reciprocal Rank Fusion (RRF) & Reranking: Configurable rank-fusion algorithm (RRF) paired with cross-encoder reranking to re-score candidate contexts before prompt augmentation.
  • Google Agent Development Kit (ADK) & MCP: Built with Google ADK for structured agent tool interactions in the deployed production API, supporting Model Context Protocol (MCP) integrations.
  • LangGraph Workflows: Multi-agent cyclical graph orchestration in a dedicated development and evaluation workflow for systematic query routing and answer validation.
  • FastAPI, PostgreSQL & Redis: Asynchronous high-throughput backend built on FastAPI, persistent relational metadata in PostgreSQL, and high-speed query response caching via Redis.
  • AWS Cloud Deployment: Cloud infrastructure deployed on AWS EC2, containerized with Docker, image registry via Amazon ECR, remote management via AWS Systems Manager (SSM), and TLS termination via Caddy.

Financial AI & Fraud Detection

FinGuard AI — AI-Powered Financial Fraud Detection & Investigation Platform

An end-to-end financial fraud detection and investigation platform combining machine learning, graph analytics, explainable risk scoring, RAG, and an LLM-powered investigation assistant.

Key Highlights:

  • Synthetic financial transaction generation with Random Forest fraud classification (baseline vs. graph-enhanced).
  • NetworkX graph-based analytics & SHAP-based model explainability for human investigators.
  • Fraud knowledge retrieval via TF-IDF and cosine similarity, assisting human reviewers without auto-freezing accounts.
  • FastAPI backend, interactive dashboard, Docker containerization, and automated GitHub Actions CI/CD.
